# Gaussian Mixture Model & Expectation-Maximization

This project studies Gaussian Mixture Models (GMM)
and the Expectation-Maximization (EM) algorithm
from both mathematical and computational perspectives.

## Objectives

- Understand mathematical foundations of GMM
- Derive EM algorithm
- Implement GMM from scratch
- Compare with Scikit-learn
- Evaluate clustering performance
